# OpenPictalis design assets

Use `readme-banner.png` for the repository README, `social-preview.png` for GitHub's social preview, `avatar.png` for a project avatar, and `app-icon-512.png` for launcher artwork. `logo.svg` is the vector logo. `brand-sheet.png` records the palette and typography. `interface-mockup.png` is an early design mockup; `../screenshots/app.png` is the supplied application screenshot.

Ground #0B0C10; Panel #12141A; Line #23262F. Accents: Amber #FFB547, Rose #FF5C8A, Indigo #6C7CFF, Teal #2FD6C5. Display type uses Bricolage Grotesque; controls use IBM Plex Mono. Full font notices are included with the web assets.

The original design PDF has placeholder repository text. Keep it as a private reference until it is updated.
