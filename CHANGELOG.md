# Changelog

## 0.1.0 — unreleased preview

- Image, Reference and Transparent modes.
- Model catalog with links and licenses: Qwen-Image 2.1 (4/8-bit), FLUX.2 Klein 4B (Draw Things or mflux), Z-Image Turbo, Qwen-Image-Edit 2511, Ming-Image Design.
- Swap models from the Model menu; add your own mflux, Draw Things or custom-command models.
- Optional Viggle Turbo LoRA for Qwen-Image 2.1.
- Local library, PNG export, Use as reference, Edit image.
- Sizes up to 2048 px plus custom width × height.
- Built-in upscaling (2×/4×): Real-ESRGAN x4plus and Anime, SeedVR2 3B, simple resize.
- macOS app wrapper (`macos/build-app.sh`).
